# How to use feature flags in GODOT Engine

This is a companion repository containing the sample project mentioned and used in the blog article titled **How to use feature flags in GODOT Engine**. The article covers the steps for using a feature flag in a GODOT application.

## Pre-requisites

- Have [GODOT installed](https://godotengine.org/download/)
- Have [.NET 10.0](https://dotnet.microsoft.com/en-us/download)

## Build & Run

With GODOT installed, here's how to run the sample GODOT project.

**1.** Clone this repo

**2.** Open `Sprite2d.cs` and replace `"YOUR-CONFIGCAT-SDK-KEY"` with your own ConfigCat SDK key.

**3.** Launch the GODOT Engine, browse to the folder, and open the project.
